**Deterministic Terraform/OpenTofu plan blast-radius and IAM escalation gate.**
Built by **Baysöz Labs <baysozlabs@proton.me>**.

`planradius` reads the JSON output of `terraform show -json` / `tofu show -json`
and answers the question static HCL linters cannot: *if this exact plan is
applied, what else can break, and which principals gain new privilege paths?*
It is fully offline, stateless, deterministic, and requires no cloud
credentials, services, or local models.

## Install

```bash
uv tool install git+https://github.com/yazilimbaysoz-svg/planradius.git
# or, from a checkout
uv venv && uv pip install -e .
planradius --version
```

Requires Python 3.13+. Zero runtime dependencies.

## Architecture

```
plan JSON -> model.py (strict parser)
          -> graph.py (dependency SCCs + reverse reachability)
          -> iam.py   (policy normalization + principal-indexed escalation)
          -> rules.py (11 deterministic rules)
          -> analyzer.py -> table | JSON | SARIF
```

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and
[docs/MARKET_RESEARCH.md](docs/MARKET_RESEARCH.md) for the full design and
ecosystem rationale.

## Usage

```bash
terraform plan -out=tfplan
terraform show -json tfplan > plan.json

planradius analyze --plan plan.json --fail-on high
planradius analyze --plan plan.json --format sarif --output findings.sarif
planradius baseline --plan plan.json --output baseline.json
planradius analyze --plan plan.json --baseline baseline.json
planradius explain --plan plan.json --address aws_iam_role.deploy
planradius rules --format table
```

Exit codes: `0` clean or below threshold, `1` finding at/above `--fail-on`,
`2` invalid input or usage error.

## Security

Findings are based on plan structure and an explicit, documented AWS action
catalog. Conditions are never guessed: when a condition is present it is
reported as unevaluated. See [SECURITY.md](SECURITY.md) for scope and limits.
